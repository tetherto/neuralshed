## Design Context

### Users

Neurophysiology and brain-computer-interface researchers working in live Jupyter
notebooks. They need to move quickly between standardized event metadata, timeline
structure, and event-specific neural or behavioral views without losing scientific
context.

### Brand Personality

Scientific, precise, and calm. The interface should build confidence through explicit
state, predictable controls, and restrained visual hierarchy rather than decorative
styling.

### Aesthetic Direction

A neutral, light, data-dense research dashboard that remains native to the Jupyter
environment. Prefer compact progressive disclosure, clear alignment, and useful
whitespace. Avoid ornamental cards, dramatic color treatments, and application chrome
that competes with the data.

### Design Principles

- Keep the timeline and event-specific data visually dominant.
- Group controls by the research question they answer, using tabs for progressive
  disclosure.
- Preserve dense information while bounding long lists with intentional scrolling.
- Make time, filter, and selection state explicit and predictable.
- Use a consistent 4-pixel spacing rhythm and the existing neutral widget language.
