# T12 channel correspondence

Participant `braingate2/T12` appears in two Human Communication datasets: [willet_2023](../../src/neuralshed/datasets/willet_2023/README.md) and [kunz_2025](../../src/neuralshed/datasets/kunz_2025/README.md). T12 has four 64-electrode arrays, two in area 6v and two in area 44, each pair with a superior (dorsal) and an inferior (ventral) array. Both Studies emit the arrays in the same column order:

| columns | array |
|---|---|
| 0-63 | `ventral_6v` |
| 64-127 | `dorsal_6v` |
| 128-191 | `ventral_44` |
| 192-255 | `dorsal_44` |

Inside each array, willet_2023 orders the electrodes as the authors' `unscrambleChans` (grid order), computed from the documented grid of its source files. kunz_2025 emits its stored order. This page tests how far column `i` is the same electrode in the two Studies. Of the sixteen T12 files the kunz Study reads, five store only the 6v pair (128 columns) and eleven store all four arrays (256 columns: seven sequence-recall files from 2023 and four `chittychittybangbang` files from December 2024). No recording is in both releases: willet_2023 covers 2022-04-28 to 2022-08-25, kunz_2025 T12 covers 2023-05-16 to 2024-12-19.

## Conclusions

- In the source files, column `i` is not the same electrode in the two releases. The willet files interleave the four arrays, and no release states the kunz order within an array.
- willet_2023's layout is fully documented. Its deposit gives the grid position of every file column, and the Study's array blocks follow it.
- kunz_2025's 6v pair is `ventral_6v` first, as twelve of its files label it and the data confirm. The four December files carry T15's array labels, and the data reject the layout those labels imply.
- kunz_2025 is consistent with the authors' `unscrambleChans` order, inferior array first in each recording half and each array in grid order. This holds as a candidate for the array order and for the electrode order of `ventral_6v`, `dorsal_6v` and `dorsal_44`. For `ventral_44` the data place the electrodes on a structured grid but do not settle its orientation.
- willet_2023 emits the `unscrambleChans` order, which is exact for it because its grid is documented. The two Studies therefore line up by column index at the candidate level. `ventral_44` (columns 128-191) uses the same grid order by convention, and its electrode-level match is weaker than for the other arrays.

## Result

| claim | status | basis |
|---|---|---|

| kunz 6v pair (`ventral_6v` 0-63, `dorsal_6v` 64-127) in the twelve files labeled `i6v`, `s6v` | verified | `source_documented`: in-file labels and the authors' MATLAB channel sets, with the data agreeing |

| kunz electrode order for `ventral_44` | unresolved | no orientation of the grid is preferred consistently. The Studies use the grid order by convention |

## Method

Each recording gives one channel correlation matrix per feature: the Pearson correlation over all samples between every pair of columns. Before computing it, each column is clipped at its own 0.1st and 99.9th percentiles. Spike-band power needs this, because in some files a single sample makes up nearly all of a channel's variance. Results on unclipped values are reported where they differ.

A hypothesis states which willet file column each kunz column records. Its similarity is the Pearson correlation between the entries above the diagonal of the kunz matrix and of the willet matrix rearranged by the hypothesis. Each kunz matrix is scored against three willet sessions (2022-04-28, 2022-06-28, 2022-08-25) and the scores are averaged.

The hypotheses cross two within-array orders, `unscrambleChans` grid order and willet's ascending file columns, with every assignment of the four physical arrays to the four kunz blocks (two for the 128-column files), plus the willet file order unchanged: 49 hypotheses for a 256-column file and 5 for a 128-column file. The shuffle baseline is 200 random orders within each physical array of the candidate.

Electrode order is also scored array by array, using only the pairs inside that array, for the grid and its seven rotations and reflections, willet's ascending order and the shuffle baseline.

## Calibration

- Known answer. willet_2023's last session was rearranged into a chosen order and scored against the other two sessions with the full procedure. The true hypothesis ranked first in all 16 cases: both features, 128 and 256 columns, true order `unscrambleChans` or ascending, clipped or not. Its margin over the next hypothesis was 0.08-0.40, and the array-by-array test put every array, `ventral_44` included, on the unrotated grid. The gap here is two to four months, against nine months to two and a half years between the releases.
- Same order across sessions. willet_2023's first session against its last scores 0.275 (crossings) and 0.369 (power) with the true order, against at most 0.226 and 0.347 for shuffles within each physical array. A whole-matrix score therefore separates electrode orders only narrowly, and most of it comes from array membership.

## Candidate map

For kunz column `k`, let `h = k // 128` be the recording half and `u = k % 128`. The willet file column is `128 * h` plus the column of that half that `unscrambleChans` sends to electrode `u`. The willet_2023 Study column is `k` itself, because `willet_2023.utils.CHANNEL_ORDER` lists the willet file columns in this order. For example, kunz columns 0, 1 and 2 are the top three electrodes of the first grid column of `ventral_6v` (willet file columns 125, 123, 121), and kunz column 64 is the top-left electrode of `dorsal_6v` (willet file column 62, Study column 64). The `ventral_44` entries (kunz columns 128-191) follow the same convention, but the data do not confirm their orientation.

## Notes for use

- Pooling T12 by column index across the two Studies rests on the candidate map. For `ventral_44` (columns 128-191) it rests on convention only.
- The kunz 128-column files hold the 6v arrays only.
- `chittychittybangbang/t12.2024.12.19_chittychittybangbang_50words_eval.mat` uses 25 ms bins. The other kunz T12 files and willet_2023 use 20 ms.
- Three kunz sequence-recall files store their crossings with a `uint8` tag on signed values, which the loader reads as `int8`.
- The power stream of `t12.2024.04.11_interleavedVerbalBehaviors_raw.mat` is a copy of its crossings and is marked invalid.
- willet_2023 marks the area 44 blocks of `t12.2022.06.14` invalid. Respect `valid` before pooling.
- Normalization differs. willet_2023 emits raw crossings (`tx2`, -4.5 x RMS) and unclipped power. kunz T12 is raw except the sequence-recall files, which are mean-subtracted per block.
